# ASH RELAY — frozen benchmark prompt

Build a complete 3–5 minute elevated-view 3D arcade action vertical slice named
**ASH RELAY** using the supplied DevLab internal scaffold and its native Three.js
WebGPURenderer stack. Do not replace the scaffold, renderer, capture contract or
test harness.

The game must include a title/start screen, short tutorial, player movement and
primary action, two distinct threat types, visible progression, one checkpoint,
pause/resume, defeat, clean restart, a mini-boss, victory, readable HUD,
desktop controls, touch controls, impact feedback, local WebAudio and a
deterministic frozen capture state.

Use only procedural/local assets already permitted by the run manifest. Do not
use network downloads, paid APIs, Tripo, Gemini, ElevenLabs, commercial assets,
Galaxy Raiders assets or Hellbullet assets.

Provide build and typecheck results, console/page/network error logs, objective
completion, pause/restart/checkpoint/victory checks, bot metrics, frozen-state
PNG/RGBA captures, live-run statistical metrics, desktop/mobile captures,
WebGPU adapter/backend identity, frame pacing, renderer resources, bounded
growth, process timing and remaining risks. Do not claim artistic quality from
entropy, edge density, contrast or nonblank metrics alone.
