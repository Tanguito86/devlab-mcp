The methodology has plausible value that DevLab does not currently encode, but
its technical stack is weaker and cannot own runtime or QA authority. A fair
benchmark is warranted only when both legs share the same internal scaffold and
verified native WebGPU stack. LEG_B receives the hashed text allowlist and no
other advantage.

Authorization does not establish that LEG_B is better. It permits the later
`DEVLAB-THREEJS-GAME-SKILLS-AB-04` sprint to test that hypothesis under the
frozen contract. The benchmark must be stopped if pair equality, isolation,
source integrity or native WebGPU gates cannot be demonstrated.
