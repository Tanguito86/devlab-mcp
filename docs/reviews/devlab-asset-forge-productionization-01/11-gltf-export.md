# glTF export

Cinder exports deterministic glTF 2.0 and GLB using the local pinned Three.js exporter. GLB is 86,732 bytes with SHA-256 `ff7c1509b939c34dc50c9e10d4c5bd4a77f9899c084e9af2f0975d68d816418b`; glTF is 110,523 bytes with SHA-256 `c4925fdf77dead88f7145e192aeaeff8c2d243a84b47a80ed8339ed55111560e`. Buffers are embedded, transforms finite, names stable, and remote URLs absent.
