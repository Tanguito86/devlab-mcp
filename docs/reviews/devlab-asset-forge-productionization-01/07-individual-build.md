# Individual build

`corepack pnpm asset-forge build cinder-relay-drone --version 1.0.0-pilot.1 --build-id <id>` executes validation, factory, geometry and budget gates, real WebGL capture, manifests, critics, export, round-trip, resource disposal and atomic promotion. The result is exactly `SUCCESS`, `CHANGES_REQUIRED`, or `BLOCKED`; partial success is not representable.
