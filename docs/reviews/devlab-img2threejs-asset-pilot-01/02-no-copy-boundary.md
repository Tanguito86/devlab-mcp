# DEVLAB-IMG2THREEJS-ASSET-PILOT-01 — no-copy boundary

`Cinder Relay Drone` is a completely original DevLab asset. Its brief, canonical
specification, procedural composition, materials, cameras, lighting, animation,
capture plan, and review evidence are authored for this pilot.

The implementation uses zero code, assets, prompts, textures, materials, URLs,
models, or generated outputs copied from `img2threejs`. The pinned checkout at
`b604139f51d6831780240e8cf1d8b21a42401d0a` remains a clean, read-only
architectural reference and is never executed, modified, bundled, or imported.

This pilot contains:

- zero external URLs or CDN access;
- zero downloaded models, splats, or external textures;
- zero React Three Fiber, SparkJS, or Blender integration;
- zero mandatory remote generation;
- zero upstream runtime, prompt, generator, scaffold, or asset reuse.

The only graphical library used at runtime is the Three.js `0.185.1` copy
already pinned by DevLab. All geometry is composed locally from its public
primitive APIs, with deterministic transforms and no network loaders.
