# Legibility

The functional pass adds preallocated hatch rings/threat cones, Guardian safe-zone and attack-ground cues, node-floor pulse, stronger player/core lighting, and explicit FSM prompts. Critical states combine geometry/motion/emissive with text and existing procedural audio.

Canonical captures cover 1280x720 and 390x844. The portrait objective uses a compact 9px line with reserved height so the full long objective remains visible beside vitals. No model or final asset was replaced.
